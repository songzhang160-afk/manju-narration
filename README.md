# 漫剧第一人称旁白助手

一个用于将小说、文案、剧本自动转换为**第一人称旁白**的 AI Skill。

适合漫剧、短剧、AI 视频、小说改编、剧情解说等场景。

## 功能

* 自动删除角色对话
* 自动删除引号内容
* 将第三人称叙述转换为第一人称
* 保留原剧情关键情节
* 压缩冗余描写
* 输出适合 AI 配音的短句
* 保持内容口语化、易朗读

## 适用场景

* 漫剧旁白
* 小说转视频
* AI 短剧
* 剧情解说
* 第一人称 POV 视频
* AI 配音文案

## 使用方式

输入一段小说、剧本或文案，并要求：

> 转成第一人称旁白

Skill 会自动按照规则处理内容，并输出可直接用于 AI 配音或剪辑的旁白文本。

## 核心规则

1. 删除全部角色对话
2. 统一转换为“我”的第一人称视角
3. 只保留剧情推进需要的信息
4. 删除重复、无关和冗余描述
5. 不额外添加原文不存在的剧情
6. 每段旁白保持简短、口语化
7. 输出纯净旁白文本

## Example

原文：

> 李明推开房门，看见桌上放着一封信。
> “你终于回来了。”母亲说道。
> 他拿起信，发现上面写着自己的名字。

转换后：

> 我推开房门，看见桌上放着一封信。
> 我拿起信，发现上面写着我的名字。
